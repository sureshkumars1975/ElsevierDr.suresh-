# ElsevierDr.suresh-

**Nil APC Journal Finder**: a React + Vite web app listing Elsevier journals you can publish in without an article processing charge (APC). Journals appear as cards in a grid, with filters for subject, access model, first letter, search and saved journals.

**Live site:** https://sureshkumars1975.github.io/ElsevierDr.suresh-/

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs a single file, dist/index.html
```

## Deployment

Every push to `main` builds the app and deploys it to GitHub Pages using `.github/workflows/deploy.yml`.

> APC policies change. Confirm on each journal's *Guide for authors* before submitting. This project is not affiliated with Elsevier.
